A

Android

Download the CA certificate and install it as a user certificate for Wi-Fi traffic inspection.

Download Android certificate
  1. Open Security or Credential settings.
  2. Choose Install certificate, then CA certificate.
  3. Select the downloaded knet-ca.crt file.
  4. Set this Wi-Fi network proxy to Manual using the server above.
i

iPhone and iPad

Download the Apple profile containing the KNet root certificate and finish trust setup.

Download Apple profile
  1. Allow the profile download, then open Settings.
  2. Open Profile Downloaded and install KNet Root CA.
  3. Enable full trust under About, Certificate Trust Settings.
  4. Set this Wi-Fi network proxy to Manual using the server above.
Development devices only. Some apps ignore user-installed certificates or use certificate pinning. Remove the KNet certificate when inspection is complete.
