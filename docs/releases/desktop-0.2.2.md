
### Changes in 0.2.2

- Keep the complete forwarding status and endpoint readable in the Traffic toolbar.
- Allow Protected Traffic tunnels to reach IPv4 origins from IPv6 CONNECT requests when the TLS hostname provides a reachable IPv4 address.
- Keep in-flight traffic forwarding on Pause Capture. Mark the retained recording as paused and display any HTTP status received before the pause.
- Show persisted GraphQL queries in a compact API Studio strip with manifest import, a copyable SHA-256 and a read-only source viewer.
- Default new breakpoints from persisted GraphQL traffic to the captured hash, endpoint and method. Use the operation selector when supplied and offer endpoint-wide matching explicitly.

KNet Desktop 0.2.2 is compatible with KNet Companion 0.2.0.
